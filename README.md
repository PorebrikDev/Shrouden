# 🟣 SHROUDEN
Сольный портфолио-проект

##Технологии

- Unity 2022.3 / C#
- Интерфейсы События Object pooling Coroutines DOTween ScriptableObjects Tilemaps..

##Особенности
- Лесной и ледяной биомы
- Система квестов (волшебник выдаёт задания)
- Отзывчивое управление (coyote time, jump buffering)

---

## 🎮 Управление
WASD - движение
F - взаимодействие
J - журнал заданий

##Сборка
- Платформа: Windows
- Формат: `.exe`
