## ✨ Ключевые особенности

- **Два биома:** Проработанные лесной и ледяной уровни с уникальной стилистикой.
- **Система квестов:** Взаимодействие с NPC (волшебник выдает задания) и удобный журнал квестов.
- **Отзывчивое управление:** Реализован профессиональный платформерный контроль (механики *coyote time* и *jump buffering* для комфортных прыжков).
- **Левел-дизайн:** Сборка и настройка уровней, работа с физикой окружения.

## 🛠 Технический стек

- **Движок:** Unity 2022.3
- **Язык:** C#
- **Архитектура и паттерны:** Интерфейсы, События (Events), ScriptableObjects, Object Pooling.
- **Анимация и асинхронность:** DOTween, Coroutines.
- **Уровни:** Unity Tilemaps.

## 🎮 Управление

| Клавиша | Действие |
|---|---|
| **A / D** | Движение влево/вправо |
| **Space** | Прыжок |
| **F** | Взаимодействие |
| **J** | Журнал заданий |

## 🚀 Сборка

- **Платформа:** Windows
- **Формат:** `.exe`

---

## Для работодателей и ревьюеров

Этот проект наглядно демонстрирует следующие навыки:

- **Понимание архитектуры Unity:** грамотное разделение игровой логики (Model) и визуальной части (View).
- **Работа с интерфейсами и событиями:** использование паттерна Observer для слабой связанности кода (Loose Coupling) и легкого масштабирования.
- **Game Feel:** настройка отзывчивого управления и физики персонажа.
- **Доведение до результата:** умение пройти путь от идеи и прототипа до готового к запуску `.exe` билда.
